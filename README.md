# 白球ロード

カードで練習を選び、部員を育て、夏の全国大会を目指す高校野球監督ゲーム。
ブラウザだけで動きます（ビルド不要・依存なし）。

## 遊び方

`index.html` をブラウザで開くだけ。進行状況はブラウザに自動保存されます。

- **練習ボード**：手札のカード（1〜6）を選ぶと、その数だけ盤面を進みます。止まったマス（打撃・筋力・走塁・守備・投球・体力・休養・イベント・練習試合・スカウト・地域交流）の効果を部員全員が受けます。★マスは効果1.5倍、「効果×2」カードは2倍。
- **部員**：一人ずつ練習メニューを設定できます（「おまかせ」は苦手を自動で鍛えます）。疲労が溜まるとケガをしやすく、試合でも力が落ちます。投手はエースに指名すると優先して先発します。守備位置のコンバートも可能。
- **大会**：7月に夏の県大会（優勝で夏の全国大会）、9月に秋季県大会（決勝進出で地区大会、地区で決勝に進めば春の全国大会）。
- **試合**：攻撃では「打て／強振／ミート／送りバント／スクイズ／盗塁」、守備では「勝負／敬遠／投手交代」を指示します。おまかせで自動進行も可能。県大会と地区大会ではコールドあり、10回以降はタイブレーク。
- **世代交代**：3年生は夏の大会で引退し、4月に新入部員が入ります。評判が高いほど有望な新入生が集まり、スカウトマスで見つけた中学生も入部します。

## 構成

| ファイル | 内容 |
| --- | --- |
| `js/data.js` | 選手・相手校の生成、盤面、日程、大会定義 |
| `js/engine.js` | 試合エンジン（打席・走塁・盗塁・継投・コールド・タイブレーク） |
| `js/game.js` | 週の進行、練習と成長、大会進行、画面描画 |
| `style.css` | スタイル（ライト／ダーク対応） |

## テスト

```sh
node tests/sim.js        # 試合エンジンの得点・勝率バランス
node tests/balance.js 3  # 3年分を高速で回して成長と大会成績を表示（Playwright）
node tests/smoke.js      # 実際にUIを操作して数年分プレイし、エラーがないか確認（Playwright）
```
