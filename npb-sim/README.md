# ペナント・マネージャー（NPB球団経営シミュレーション）

ブラウザだけで動く、架空の12球団による日本プロ野球の球団経営シミュレーションです。GM兼監督として何シーズンも球団を運営します。選手・球団・学校・新聞はすべて架空です。設計と各フェーズの記録は [docs/PLAN.md](docs/PLAN.md)。

## 遊び方
```
npm install
npm run dev       # 開発サーバー（http://localhost:5173）
npm run build     # dist/ に書き出し（静的ファイルとしてどこにでも置けます）
npm test          # テスト（エンジン・日程・セイバー・ポストシーズン・複数シーズン・アマチュア・財政）
npx vite-node scripts/fit-tuning.ts   # リーグ平均への自動調整
```

## 主な機能
- 試合エンジン: オッズ比法の打席モデル、走塁・守備・疲労・左右、采配AI、NPB平均に合わせた調整（テストで確認）
- 143試合の日程（3連戦・月曜休み・交流戦・球宴休み）、順位、成績、セイバーメトリクス（係数はゲーム内リーグから算出）
- 試合観戦（俯瞰図のアニメーション、1球〜試合終了まで、作戦・選手交代）
- CS・日本シリーズ・オールスター・タイトル・各賞、スポーツ新聞「白球スポーツ」と過去の紙面
- 成長・衰え・ケガ・引退、ドラフト（入札抽選・ウェーバー・育成）、FA、契約更改、トレード、外国人、現役ドラフト
- 高校・大学・社会人野球の世界（センバツ・甲子園・大学選手権・神宮大会など）とスカウト、プロ志望届
- 二軍（ファーム東西2地区）、球団の財政（観客動員・収入・年俸・予算、チケット価格と育成投資）、歴代記録
- セーブ（IndexedDB 5枠＋オートセーブ、ファイル書き出し/読み込み）、Web Worker による一括計算、スマホ対応

## 構成
- `src/engine/` 試合エンジン（DOM非依存の純粋TypeScript）
- `src/league/` リーグ運営（日程・ポストシーズン・ドラフト・FA・トレード・財政・記録）
- `src/amateur/` 高校・大学・社会人野球とスカウト
- `src/stats/` セイバーメトリクス、`src/news/` 新聞、`src/save/` セーブ、`src/worker/` Web Worker、`src/ui/` 画面（Preact）
