# ほしかげの剣 II ―なまえを なくした せかい― 設計書（GDD）

2作目は `rpg2.html`。1作目（`rpg.html`）の戦闘・成長・バランス調整の仕組みを土台にし、
1作目で単調だった **物語・探検・町のつくり** を、調べたプロの手法で作り直す。

## 0. 1作目の反省と、2作目で使う手法

| 1作目の問題 | 原因 | 2作目で使う手法（出典の要点） | 具体策 |
|---|---|---|---|
| 町がどれも同じ | ガルドの町の配置を色替えして使い回した | 町には存在理由（産業）・ランドマーク・地区・出来事を持たせる。目的地にも道しるべにもなるランドマークを置く。意味のないNPCは置かない | 町ごとに「産業・ランドマーク・配置の型・その町だけの出来事」を決める。建物に入れる（内装あり）。NPCは全員が情報・世界観・頼みごとのどれかを持つ |
| 探検しがいがない | 宝箱以外に見つける物がない。歩くだけ | 広さより密度。ランドマークで好奇心を引く。隠し要素の報酬は能力・物語・唯一の品に。本筋は明確に、寄り道は報酬付きで任意 | つぼ・たる・本棚・草むらを「しらべる」。100個の「ほしのかけら」と交換所。フィールド能力（かま・ハンマー・ランタン）で行ける場所が増える。隠し部屋 |
| ダンジョンが全部同じ迷路 | 自動生成の迷路だけ | 鍵で本筋から外れさせて探索させる（ゼルダ）。仕掛けを紹介→発展→ひねりで使う | 小さなカギと扉、スイッチと格子、隠し通路、暗闇（ランタン）、見張りをよける潜入、連戦の防衛戦 |
| 物語が「町→洞窟→ボス」の繰り返し | 毎章同じ型 | 地域ごとに完結する話を1本の謎でつなぐ（ドラクエ7の島ごとの構成）。同じ型の連続は飽きられる（オクトパストラベラーへの批判） | 24章をすべて違う型（祭り・潜入・裁判・防衛戦・幽霊の町・王の護衛・試験・鍛冶・過去編・鏡の世界…）にする |
| 仲間に物語がない | 加入して終わり | 仲間の成長を「どんな人か→変わる動機→変化」で描く。伏線を早めに張り、どんでん返しを納得できるものにする。悪役の動機を主人公の個人的な事情に結びつける | 6人の仲間それぞれに個別の章。主人公の妹の正体を序盤から伏線で示す。悪役ムメイの動機を物語の中で体験させる（過去編） |
| サブクエストがない | — | 数より質。本編のテーマにつながり、結果が世界に残る。種類を変える | テーマ「なまえ・記憶」に沿った30件。結果で町のセリフや報酬が変わる |

## 1. テーマと柱

- **テーマ**：「名前を呼ぶこと＝誰かを覚えていること」。
- **柱1 物語**：章ごとに違う「名前を奪われた人」の小さな物語と、それをつなぐ大きな謎（主人公の家族）。
- **柱2 探検**：歩くほど見つかる。調べる・切り開く・壊す・照らす。
- **柱3 町**：町に入ると「ここはどんな町か」がひと目で分かる。
- **柱4 仲間**：6人それぞれに過去と変化がある。

## 2. 世界と物語

### あらすじ

千年前、ほしかげの勇者が夜空に星を取り戻した世界。いま、人の「なまえ」を食べる現象が広がっている。
名前を食べられた人は「かげびと」になり、誰からも見えず、誰からも忘れられる。
灯台守の息子である主人公は、なぜか「かげびと」の少女が見える。少女は自分の名前を覚えていない。

### 大きな謎と伏線（序盤に置き、中盤で回収）

主人公の家にはベッドが2つあり、母は理由も分からず3人分の食器を並べる。机には2人の子どもの絵。
少女は主人公の好物や癖を知っている。→ **第8章で少女は主人公の妹「ミオ」だったと分かる。**

悪役 **ムメイ** は、千年前に世界を救ったのに歴史から名前を消された本当の英雄。
「忘れられる痛みを全員に」と名前を食べている。→ 第22章の過去編で、プレイヤー自身がムメイとして彼の悲劇を体験する。
最後は彼の名前を「呼ぶ」ことで救い、彼に取りついた「わすれの かみ」と戦う。

## 3. 町づくりのルール

1. **型を変える**：十字路型（中央広場）、大通り型、港型（桟橋と海）、点在型（村）、城下町型（奥に城）、輪型（中央の名所を囲む）を使い分ける。
2. **ランドマーク**：町に1つ、町の産業を表す名所（灯台、花畑、鉱山の昇降機、噴水市場、時計塔…）。
3. **建物に入れる**：宿屋・武器屋・道具屋・民家・教会・酒場・図書館などの内装。つぼ・たる・タンス・本棚を調べられる。
4. **NPCは全員役目がある**：「情報」「世界観」「頼みごと」「物語の進行」のどれか。章が進むとセリフが変わる。
5. **昼と夜**：歩くと時間が進む。夜は町の顔ぶれが変わり、夜だけの出来事がある。宿屋で朝になる。

## 4. 探検のルール

- **しらべる**：つぼ・たる・タンス・本棚・草むら・フィールドの「きらきら」。
- **ほしのかけら**：全100個。交換所で唯一の装備・道具と交換。
- **フィールド能力**：かま（2章、草むらを切る）、ハンマー（3章、ひび割れた岩を壊す）、ランタン（6章、暗いダンジョンを照らし隠し通路を見つける）。前に通れなかった場所へ戻ると新しい発見がある。
- **乗り物**：船（8章）、空飛ぶ船（16章）。
- **本筋と寄り道**：本筋は「もくてき」で常に分かる。寄り道（隠し部屋・任意ダンジョン・サブクエスト）には必ず報酬を置く。

## 5. ダンジョンのルール

- **鍵と扉**：本筋上の扉を閉め、小さなカギを脇道の行き止まりに置く（脇道を探検させる）。
- **スイッチと格子**：床のスイッチを踏むと格子が開く。
- **隠し通路**：ひび割れた壁（ハンマー）と、ランタンで見える隠し通路。先には宝。
- **暗闇**：ランタンがないと視界がほぼない。
- **潜入**：見張りの視線に入ると見つかり、入口へ戻される。
- **中ボス・連戦**：一部の章で。
- 仕掛けは章を追って「紹介→発展→ひねり」で組み合わせを増やす。

## 6. サブクエスト（目標30件 → 実装22件）

種類を変える：届け物、探し人、討伐、謎解き、収集、交換の連鎖、選択、護衛、夜だけ、仲間の過去。
どれも「なまえ・記憶」のテーマにつながる。報酬は装備・能力・物語・町の変化のどれか。
メニュー「クエスト」で一覧と進み具合を確認できる。

## 8. バランス

1作目と同じ方法（`docs/design.md` §4・§6）を使う：ダメージ式は固定、敵は場所の想定レベルから式で決め、
ボスは自動戦闘AIのシミュレーションでHP倍率と攻撃倍率を調整する。目標は章ボスの勝率60〜90%、
雑魚戦は2.5〜4ターン・HPの1〜2割消耗、章ボスを倒した時点で目標レベル＋1〜2。

### 自動テスト（`tools2/`）

- `check.js`：存在しないIDのチェック、全マップで「入口から全扉・全NPC・全宝箱・全しらべ物に届くか」→ 0件。
- `world.js`：世界地図の進み方。始め＝アカリ周辺 → かま → ハンマー → 橋 → 船 → 飛行船 の順にだけ行き先が増え、行けない場所は0。
- `story.js`：1章からエンディング・クリア後ボスまで、目安レベルと店売り装備で自動進行。全章の会話・仲間加入・章カード・過去編・最終戦・エンディングが例外なしで通る。
- `story.js 0 N`：各ボスをN回ずつ戦わせて平均ターン数・勝率・最低HP割合を記録し、`tunecalc.js` で `TUNE`（HP・攻撃の倍率）を計算。3回くり返して収束させた。
- `mobs.js`：各地域の雑魚戦（8回ずつ）。平均2〜4ターン、1戦あたりHPの7〜18%を消耗（町の外は軽め、ダンジョンは重め）。

### ボスの目標と結果（目安レベル、自動戦闘）

章ボスは平均 9〜14 ターン、最終形態は約19ターン。目安レベルでの勝率はほぼ100%だが、戦闘後に一番減った仲間のHPは平均4〜6割まで減る（回復とぼうぎょを使わないと負ける）。

**むずかしさ調整（2回目）**：遊んだ人から「もっと難しくていい」との声があり、全体の倍率 `HARD`（ボス攻撃×1.2、ざこHP×1.1・攻撃×1.15）を足して、勝率の極端なボスを個別に直した。目安レベルでの章ボス勝率は67〜100%（平均約9割）、戦闘後に一番減った仲間のHPは2〜4割。ざこ戦は1戦でHPの9〜23%を消耗。

**ボスの技を本家寄りに（3回目）**：「本家のボスはもっと難しい？」という質問から、ボスのしくみを3つ足した。① HPが半分を切ったあとは毎ターン2回行動（3章以降のボス）。② 9章以降の章ボスは「かきけしの ひかり」で強化（まもり・ちからのうた・たてのかまえ等）を全部消す。必ず1ターン前に予告する。③ 9章以降の章ボスは「じゅもんふうじ」（3ターン呪文が使えない。じょうか・めざましベルで治る。44レベル以降のボスは全員にかける）。そのままでは勝率が大きく下がったため、測定→調整を5回くり返した。目安レベルでの章ボス勝率は50〜100%（平均 約9割）、戦闘後の一番減った仲間のHPは1〜5割。自動戦闘AIはふうじられた回復役をすぐ治すので、人が遊ぶと数字より難しく感じるはず。

**レベル上げの速さ（4回目）**：「レベル上げが1作目よりしやすい」との指摘。1作目は地域ごとの経験値倍率（平均 約0.5）を入れていたが2作目では未設定で、1レベルが雑魚4〜6戦で上がっていた。雑魚の経験値を一律0.45倍（`EXP_FIELD`）にして、目安レベル付近で1レベル＝9〜13戦にそろえた。ボスの経験値はそのまま。
