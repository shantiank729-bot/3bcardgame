# ほしかげの剣 大型アップデート設計書（GDD）

この文書は、`rpg.html` をレベル上限50・全15章のRPGへ拡張するための設計書です。
実装は必ずこの文書の数値と構成に従い、変えるときは先にこの文書を直します。

## 0. 調査で採用したプロの手法

| 手法 | 出典の要点 | このゲームでの使い方 |
|---|---|---|
| 最大レベルを先に決め、内容に合わせてカーブを引く | 「まず最大レベルを決め、コンテンツと進行に合わせて曲線を調整する」 | Lv50上限を決め、章ごとの到達レベルを表にしてから経験値と敵の強さを逆算する（§3, §4） |
| 単純で固定のダメージ式＋敵の数値で難易度を作る | Dungeon Siege 2 のチームは基本式を誰でも分かるほど単純にし、防御は固定、敵HPとダメージだけで難易度を調整した | ダメージ式 `(攻撃 − 守備/2)/2` は変えない。敵の数値を「何発で倒せるか」から式で出す（§4） |
| 1つの町・1つの問題・1つのダンジョン | Grandia II の分析：町ごとに問題を1つ出し、ダンジョンとボスで解決させる | 各章を「町 → 問題 → ダンジョン → ボス → 報告」で作る（§2） |
| 同じループの繰り返しは飽きる | Octopath Traveler への批判：どの章も全く同じ流れ | 船旅・空の旅・連戦・2体同時ボス・予告大技など、章ごとに違う遊びを1つ入れる |
| のこぎり型の難易度 | 章の終わりにボスで山を作り、次の区間は落ち着かせる | 章ボスは強め、次の町の周りは一段弱めの敵から始める |
| ボスは予告→対応、段階で「習ったこと」を組み合わせる、後出しの新ルールは禁止 | 予告・対応・罰のループ、最終段階は既知の仕組みのリミックス | 大技は1ターン前に予告（「ちからを ためている…」）、HPで段階変化、最終ボスはそれまでのボスの技の組み合わせ（§5） |
| 乗り物で世界が広がる・鍵で進行を区切る | ドラクエは乗り物で歩けない地形を越えさせ、鍵で扉を開けさせる | 第6章で船、第11章で空飛ぶ「そらくじら」。通行証・封印・結界で順番を作る（§2） |
| テストプレイで確かめる | 「戦ったテスターが理不尽と感じたら直す、惜しいと感じたら成功」 | 自動で戦うテスト用AIで全ボスを目標レベルで繰り返し戦わせ、勝率を測って調整（§6） |

参考にした資料は本文末にまとめています。

## 1. 柱（ピラー）

1. **ほしを取り戻す旅**：章が進むたびに夜空の星が戻っていく物語。
2. **仲間4人のパーティ**：勇者（回復と剣）、魔法使い（攻撃魔法）、戦士（物理技）、僧侶（全体回復）。
3. **世界が広がる気持ちよさ**：徒歩 → 船 → 空。
4. **迷わない**：メニューの「もくてき」で今やることがいつでも分かる。

## 3. 成長曲線

- **レベル上限：50**
- 必要経験値（累計）：`5 × (Lv−1)^2.2 + 5 × (Lv−1)`（Lv21までは従来と同じ式で、旧セーブとずれないようにする）
- **章ごとの到達目標レベル**は §2 の表のとおり。

## 4. バランスの式（敵の数値の決め方）

ダメージ式は全員共通で変えません：`ダメージ = (攻撃力 − 守備力/2) / 2 × (0.85〜1.15)`。

新しい敵は「その場所の想定レベル（ML）」と「その章で買える装備」から、次の目標で数値を出します。

| 目標 | 内容 |
|---|---|
| 倒すまでの手数 | 通常の敵は、戦士の通常攻撃で約3発 |
| 受けるダメージ | 敵の通常攻撃1発で、パーティ平均最大HPの約10% |
| 経験値 | 同じ場所で約5回戦うと1レベル上がる量（1戦平均1.8体） |
| ゴールド | その章の装備一式が、章の戦闘＋宝箱で買える量 |
| ボスのHP | 想定パーティが10〜14ターンで倒せる量 |

敵には型（タイプ）があり、上の基準に倍率をかけます：ふつう／かたい（HP・守備↑、素早さ↓）／すばやい（素早さ↑、HP↓）／まほう（呪文中心、HP↓）。

## 5. ボス設計のルール

1. **大技は必ず予告する**：「〜は おおきく いきを すいこんだ！」→ 次のターンに大技。ぼうぎょ・まもりで対応できる。
2. **段階はHPで変わる**：50%前後で形や行動が変わり、セリフで知らせる。
3. **最終段階は既知の技の組み合わせ**：最後に初めて見る仕組みを出さない。
4. **章のボスは1つの仕組みを試す**（§2の「ボスで試すこと」）。
5. **ねむり系はボスに効かない**：ボス戦が作業にならないようにする。

## 6. テストと調整の進め方

1. 全マップを自動で調べ、入口・階段・宝箱・人にたどり着けるか確認（船・空の乗り物も含む）。
2. テスト用の自動戦闘AI（回復・蘇生・補助・強い呪文を状況で使い分ける）で、各ボスを**目標レベル・その章の装備**で20回ずつ戦わせる。
3. 目標：章ボスの勝率 **60〜90%**（人間が道具を使えばもっと勝てる幅）、最終ボスは50〜80%、裏ボスはLv50で40〜70%。
4. 外れたボスはHPと攻撃力の倍率だけを動かして再測定する（ダメージ式は動かさない）。
5. 物語を最初から最後まで、フラグだけで進めるテストで、章の順番が詰まらないことを確認する。

## 7. テスト結果（このアップデートで実施）

すべて `tools/` のスクリプトで再実行できます（Playwright が必要）。

### 7-1. ボス戦（自動戦闘AI、目標レベル・その章の装備・妥当な道具、各20〜40戦）

自動戦闘AIは「倒れた仲間の蘇生 → 2人以上が瀕死なら全体回復 → 瀕死の仲間を回復 → ボス戦の初手で まもり・ちからのうた → 予告大技の前は弱い仲間がぼうぎょ → 残りMPで最強の攻撃」という、そこそこ上手なプレイヤーの手順で戦います。

調整の手順：最初の式のままでは全ボスが勝率100%・5〜10ターンで終わり簡単すぎたため、
§6 のとおり「HP倍率でターン数を目標へ → 攻撃倍率で勝率を目標へ」を自動で繰り返し、
決まった倍率を `rpg.html` の `TUNE` に記録した。

### 7-2. 雑魚戦（攻撃だけで戦うAI＝MPを節約する遊び方、各24戦）

全19エリアで勝率100%、1戦 **2.7〜4ターン**、1戦でパーティHPの **9〜20%** を消耗（目標どおり）。
最初は旧大陸の敵が今の4人パーティには弱すぎ（1ターン・HP2%）、序盤の1人旅は厳しすぎた（勝率29%）ため、
雑魚の数値を「出てくる場所の想定レベル」から式で決め、仲間が少ない序盤だけ弱める補正（`ZONE_MUL`）を入れた。

### 7-3. 成長の進み方（普通に進めた場合の見積もり）

各章の戦闘回数の見込み（外で8〜14戦＋ダンジョン1階あたり約5戦）から計算し、章ボスを倒した時点で
**目標レベル＋1〜2** に届くよう、場所ごとの経験値倍率（`EXPMUL`）を決めた。ラスボス到着時はLv47（目標47）、
Lv50 はクリア後の「ほしふるめいきゅう」で到達する。

### 7-4. 進行と移動

- 物語を第1章からクリア（第16章＝クリア後）まで、フラグとイベントだけで進めるテストでエラーなし。
- 徒歩で行ける場所：旧大陸とカザン。船で増える場所：シオサイ・ユキノ・アルマと各ダンジョン。
  空でしか行けない場所：ルミナ・かぜのめいきゅう・やみのしんでん・ノクスのしろ（設計どおり）。
- 全マップで出入口・階段・人にたどり着ける。届かない宝箱はボスの奥のごほうび13個だけ（意図どおり）。
